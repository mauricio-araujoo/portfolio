Contato

Entre em contato por e-mail, LinkedIn ou formulário para solicitar orçamento técnico.

Se você tem um sistema, integração, automação ou processo técnico travado, envie uma descrição curta do problema e do prazo desejado.

Não precisa enviar uma especificação completa. Explique o problema atual, o que deveria acontecer e o prazo desejado.

Opções de contato Link para o cabeçalho

E-mail

Use o e-mail como canal principal para enviar contexto técnico e arquivos de apoio.

Enviar e-mail

LinkedIn

Canal útil para uma primeira conversa e alinhamento rápido de disponibilidade.

Abrir LinkedIn

Formulário

Enquanto um endpoint externo não estiver configurado, o envio usa o cliente de e-mail do navegador.

O formulário não usa chave secreta no repositório. Para envio direto por serviço estático, configure um endpoint conforme `FORM_SETUP.md`.

O que enviar Link para o cabeçalho

  • Qual problema você quer resolver.
  • Qual sistema, stack ou ferramenta está usando.
  • O que já existe hoje.
  • Qual erro, log, tela ou comportamento motivou o contato.
  • Se há repositório, ambiente, print ou trecho de log para analisar.
  • Qual prazo ou impacto esperado.
