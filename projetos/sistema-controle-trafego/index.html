Projeto acadêmico

Sistema distribuído de controle de tráfego

Controle acadêmico de semáforos com Raspberry Pi, ESP32, GPIO, comunicação serial e processos distribuídos.

  • C++
  • Raspberry Pi
  • ESP32
  • GPIO
  • UART
  • RS485
  • MODBUS
  • TCP/IP
  • Linux

Contexto Link para o cabeçalho

Projeto acadêmico com integração entre software, hardware e comunicação local para controle de cruzamentos.

Problema Link para o cabeçalho

O sistema precisava controlar semáforos, ler botões de pedestre e coordenar comunicação entre componentes físicos e processos distribuídos.

Minha atuação Link para o cabeçalho

Implementei controle de semáforos, leitura de botões, debounce, execução concorrente com threads, comunicação UART, protocolo simplificado, wrapper MODBUS modificado e reestruturação para arquitetura com processo central e processos distribuídos.

Também houve uso de sockets TCP/IP locais, sinais Linux e finalização limpa de processos.

Solução Link para o cabeçalho

A solução separou responsabilidades entre controle central, processos distribuídos e comunicação com dispositivos. A concorrência tratou leituras físicas e atualização de estado sem bloquear o fluxo principal.

Arquitetura Link para o cabeçalho

Processo central → sockets TCP/IP locais → processos distribuídos → GPIO/UART/RS485 → semáforos, botões e ESP32.

Resultado Link para o cabeçalho

  • Controle de semáforos implementado.
  • Leitura de botões de pedestre com debounce.
  • Comunicação local com sockets, UART e MODBUS adaptado.
  • Encerramento de processos tratado com sinais Linux.

Tecnologias Link para o cabeçalho

C++, Raspberry Pi, ESP32, WiringPi, GPIO, UART, RS485, MODBUS RTU, TCP/IP, sockets, threads, mutex, condition variable, fork(), waitpid(), SIGINT, Makefile e Linux.

Aprendizados Link para o cabeçalho

  • Sistemas com hardware exigem tratamento cuidadoso de tempo, concorrência e falhas físicas.
  • Encerramento limpo de processos é parte importante de sistemas distribuídos locais.
  • Protocolos simples ajudam a validar comunicação antes de aumentar complexidade.
